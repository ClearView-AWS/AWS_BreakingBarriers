## Stage rules

1. **One voice at a time.** Others freeze; no sidebar chatter.
2. **Scripts are timed at ~140 wpm.** If you run long, cut the italic *optional* lines first.
3. **Never debug live.** Call fails → Person D reads the backup block immediately.
4. **Hard-refresh** the demo once before you walk on stage.
5. First chip (Person B):

```text
Middle school in Seattle that must have a gifted program and after-school care. Prefer a small school.
```

6. Call path (Person D): after Seattle, refine or new search to Jacksonville after-care **or** use a Seattle card that still shows **Have AI call** (after-care Unknown). Prefer Jacksonville/Beauclerc if you need the 13-parent community beat.
